> Shipped solo to the **App Store** and **Google Play**: **250+ downloads**, **100+ MAU**.
> Firebase/Firestore backend with real-time sync and an LLM-powered financial assistant. Built a **Plaid** bank-aggregation pipeline with idempotent webhooks and cursor-based incremental sync — **24 months** of history, **$500K+** in transactions, zero duplicate ingestion.
> An AI engine detects merchants, auto-categorizes spending, and surfaces recurring subscriptions at **95%** fuzzy-match accuracy, plus receipt scanning and a greedy two-pointer debt settler that runs in **O(n)** instead of **O(n²)**.
>
> `Swift` `SwiftUI` `Dart` `Firebase` `Plaid API` `LLMs`

**🤖 ApplyDock — AI job-application platform** · *Mar 2026 – present*
> A **distributed multi-agent system**: a fleet of cloud-hosted **Playwright** agents auto-fill and submit applications across nearly any job board, with retry logic and per-agent failure isolation — users apply to **4× more jobs** in parallel.
> Express/Node REST microservices behind a Next.js frontend, containerized with Docker and deployed on cloud VMs with GitHub Actions CI/CD, scaling to **200+ applications per week**. Debugging live distributed failures lifted end-to-end submission success **3×**.
>
> `TypeScript` `Node.js` `Express` `Playwright` `Next.js` `Docker` `SQLite` `Azure/AWS`

**📈 [Claude AI Trading Assistant](https://github.com/AhmadAbdullahh/robinhood-api-trading)** · *Jan 2025 – present*
> Conversational trading agent built on **Anthropic Claude** and **MCP servers** — real-time stock and crypto orders in natural language via the **Robinhood** and **Alpaca** APIs, **50+ trades per session** under scoped permissions.
> A scheduling engine runs automated strategies (DCA, limit triggers, momentum entries) from reusable templates, cutting manual trade management **90%**.
>
> `Python` `Claude / MCP` `Robinhood API` `Alpaca API`

**🦾 Maze-Solving Robot** · *Mar 2024 – May 2024*
> Autonomous robot in **Python** and **MATLAB** on Linux, fusing multiple sensors for real-time navigation and path correction. Led algorithm development and system integration — **70% faster** than competing teams, finished weeks ahead of schedule.

> `Python` `MATLAB` `Linux`
